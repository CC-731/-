# 🐎 黑马记账

一个简单、直观、美观的个人记账工具。记录日常开支，看清钱花在哪里。

目前支持浏览器运行，也可以打包为独立的 Windows 桌面应用。

---

## ✨ 功能一览

- **📝 记一笔** — 记录金额、日期、分类、备注，随手记不费力
- **📋 账单列表** — 按时间倒序查看所有账单，支持按分类筛选
- **📊 统计看板** — 按分类汇总支出，一眼看清各项占比
- **🏷️ 分类管理** — 内置 10 大类 60+ 小类，还支持自定义分类
- **📥 Excel 导出** — 一键导出账单到 Excel 文件

---

## 🖥️ Windows 桌面版

项目已经接入 Electron，可以生成两种 Windows x64 程序：

- **安装版**：支持选择安装位置，并创建桌面和开始菜单快捷方式
- **免安装版**：下载后直接双击运行

### 构建安装包

```bash
npm install
npm run package:win
```

构建完成后，安装版和免安装版会出现在 `release/` 目录。

> 安装包暂未使用商业代码签名证书。Windows 如果显示“未知发布者”，可点击“更多信息 → 仍要运行”。

桌面版账本保存在当前 Windows 用户的数据目录中，不会写入安装目录，更新应用时不会覆盖账本。

## 🚀 浏览器方式运行

### 准备工作

电脑需要安装 **Node.js**（版本 18 或以上）。

> 如果你还没装 Node.js，去 [nodejs.org](https://nodejs.org) 下载安装即可。

### 安装依赖

```bash
npm install
```

### 启动应用

```bash
npm start
```

运行后会自动打开浏览器，访问 **http://localhost:3456** 就能用了。

关闭命令行窗口即可停止。

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| React 18 + TypeScript | 前端界面 |
| Ant Design 5 | UI 组件库 |
| Vite 5 | 构建打包 |
| Node.js + Express | 后端服务器 |
| sql.js (SQLite) | 本地数据库 |
| Electron 28 | Windows 桌面应用容器 |
| electron-builder | 生成安装版和免安装版 |

## 📁 项目结构

```
├── server/          # 后端：API + 数据库
├── src/             # 前端：界面代码
│   ├── pages/       # 页面（记账、列表、统计、分类管理）
│   ├── components/  # 通用组件
│   ├── api/         # 与后端通信
│   └── data/        # 分类数据
├── electron/        # Electron 桌面应用入口
├── dist/            # Web 前端构建输出
├── dist-electron/   # 桌面端代码编译输出
├── release/         # Windows 安装包输出
└── start.ts         # 启动脚本
```
