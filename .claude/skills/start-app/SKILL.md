# 启动黑马记账应用

## 步骤

1. **关闭旧进程**：杀掉占用 3456 端口的旧 Node 进程（使用 `cmd //c` 前缀执行 Windows 命令）
2. **启动应用**：运行 `npm start`
3. **验证启动**：确认服务器运行在 http://localhost:3456

## 注意事项

- 如果端口未被占用（没有旧进程），跳过杀进程步骤继续启动
- 启动后弹出浏览器访问 http://localhost:3456
- 命令需要在项目根目录 `d:\黑马记账app` 下执行
